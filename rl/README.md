# `rl/` — Empty reinforcement-learning stage

`train_rl.py` is **intentionally empty**.

BitNet b1.58 ships pre-training, SFT, and DPO. The official technical report leaves PPO/GRPO-style reinforcement learning as future work. This directory extracts that vacant stage as a distributeable empty file next to the BitNet architecture.

See [`docs/WHITE_PAPER.md`](../docs/WHITE_PAPER.md) for the plan to fill it (Agenda A: RL for BitNet; Agenda B: RL with BitNet on the edge).
